Claude Design 탭에 붙여넣는 프롬프트
=====================================
※ 아래 ---- 줄 사이를 복사해서 Claude Design 에 붙여넣으세요.
※ 1번을 먼저 넣고, 결과를 본 뒤 2~4번으로 다듬습니다.


================================================
1 · 첫 시안 요청  (이것부터)
------------------------------------------------
한국 공공데이터로 만든 "주야간보호센터 돌봄 밀도 비교" 모바일 웹페이지를
다시 디자인해줘.

사용자: 타지에 사는 50대 보호자. 부모님 보낼 주야간보호센터를 고르는 중.
급하고, 이동 중이고, 휴대폰으로 본다.

핵심 숫자 하나: "요양보호사 1명이 어르신 몇 분을 돌보는가" (정원 ÷ 요양보호사).
적을수록 좋다. 이 숫자가 화면에서 가장 커야 한다.

화면 구성(이 순서를 지킬 것):
1) 제목 + 한 줄 설명
2) 시·도 / 시·군·구 선택 2개, 기관명 검색칸(선택), "중앙값보다 적은 곳만" 토글,
   "이 결과 링크 복사" 버튼
3) 지역 요약 한 줄 — "서울특별시 관악구 27곳 · 서울특별시 중앙값 4.8명"
   (스크롤해도 고정)
4) 기관 카드 목록. 카드 하나에 들어갈 것:
   순위 / 기관명 / 주소 / 1인당 숫자(가장 큼) /
   "정원 21명 ÷ 요양보호사 11명" / 중앙값 대비 막대 /
   "중앙값보다 적습니다" 배지 / 간호인력·사회복지사 /
   [전화번호 찾아보기] 버튼 / 공단 포털 링크
5) 하단 출처·기준일·한계 고지

지켜야 할 제약:
- 색은 3개까지. 강조색은 틸 그린 1개만(#0a6b5c 계열)
- 한 화면에 강조는 1인당 숫자 하나뿐
- 화면에 보이는 글자는 15px 아래로 내려가지 않는다 (50대 사용자)
- 중앙값 수치는 화면에서 딱 한 곳에만 (요약 줄). 카드에서는 반복하지 않는다
- 빨강 쓰지 말 것 — 기관을 나쁘다고 단정하는 서비스가 아니다.
  중앙값보다 많은 곳은 중립 회색
- 그라데이션·아이콘 남발·장식 애니메이션 금지
- 다크 모드도 같이

모바일(390px 폭) 기준으로 먼저 보여주고, 그다음 데스크톱.


================================================
2 · 비교안 요청  (1번 결과가 밋밋하면)
------------------------------------------------
같은 제약으로 분위기가 다른 시안 3개를 나란히 보여줘.
A) 지금처럼 카드형
B) 정보 밀도를 높인 리스트형 (한 화면에 더 많이 보이게)
C) 1위를 크게 띄우고 나머지를 작게 (히어로형)

각 안마다 "50대가 3초 안에 1순위를 찾을 수 있나"를 기준으로
장단점 한 줄씩 적어줘.


================================================
3 · 부분 수정  (마음에 안 드는 부분만)
------------------------------------------------
[무엇이] [어떻게] 되었으면 좋겠어. 그 부분만 고쳐줘.
나머지는 그대로 둬.


================================================
4 · 코드로 받기  (시안이 확정되면)
------------------------------------------------
이 디자인을 외부 라이브러리 없이 HTML + CSS 한 파일로 만들어줘.
- 폰트는 시스템 폰트만 (Pretendard 없으면 맑은 고딕으로 대체)
- CSS 변수로 색·크기 토큰을 :root 에 모아줘
- 다크 모드는 prefers-color-scheme 으로
- 데이터는 더미 3건만 넣어줘 (실제 데이터는 내가 연결할 것)


================================================
결과를 받은 뒤 — 나(Claude Code)에게 넘기는 법
------------------------------------------------
· 이미지 시안이면  → 캡처해서 채팅에 붙여넣기
· 코드로 받았으면  → 코드 전체를 복사해서 붙여넣기
· "이 느낌으로 바꿔줘" 한마디면 내가 tools/build_html.py 에 반영하고
  검증·배포까지 한다.

※ 주의: 받은 코드를 그대로 쓰면 안 된다.
  지금 화면은 5,346곳 데이터를 담은 자체완결 HTML이고,
  검증 스크립트(verify_screen.py)가 숫자를 대조하고 있다.
  디자인만 옮기고 데이터 구조는 유지해야 한다.
